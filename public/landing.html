Your whole build, on screen

VibeLog pulls from git, Claude, OBS and your social accounts — then renders it as one coherent, on-brand overlay. No spreadsheets, no manual updates.

Live OBS overlay

Drop one URL into OBS as a browser source. Your build telemetry broadcasts itself — transparent background, neon native.

Token & cost tracking

Per-project Claude token and spend attribution via ccusage — keyed on each repo's git remote, so you always know where the budget went.

Commits & features

Git activity tracked per project and rolled into a build feed of the features you've shipped — not raw diffs, just clean milestones.

Stream time

Connect OBS over WebSocket and VibeLog captures your live hours automatically — every session counted, no stopwatch required.

Channel growth

Twitch & YouTube followers, subs and viewers — with growth deltas so your audience watches the numbers climb in real time.

AI feature summaries

Gemini Flash-Lite turns what you're prompting into a crisp, viewer-friendly feature label — with a local template fallback when offline.

Activity calendar

A GitHub-style heatmap of your year, switchable between AI usage, streaming hours, and a combined VibeLog score.

Theming engine

10 curated neon presets, a randomize button, custom color pickers, and per-page sync — make VibeLog look like your channel.

Share cards

Public share page with rich OG / Twitter unfurls, plus preset images of your daily stats so every link looks the part.

Integrations hub

Connect Twitch, YouTube, Discord and GitHub right from the dashboard. Tokens stay in a local, chmod-600 secrets file — never on screen.

Up in minutes

Three steps to live

Local-first means there's nothing to provision. Clone it, point it at your work, and broadcast.

1

Clone & init

Grab the repo and run init. No account, no cloud, no build step — it's a single Node process.

$ pnpm install
$ vibe init
2

Connect your work

Point VibeLog at your repos and link Twitch / YouTube / OBS. Secrets land in a local chmod-600 file.

$ vibe twitch login
$ vibe start
3

Drop it in OBS

Add the overlay URL as a browser source and you're streaming your public development.

# Browser source →
http://localhost:4545/overlay
Three surfaces, one source of truth

Where your build shows up

The same live state powers three views — each tuned for a different audience.

Overlay /overlay

The OBS browser source. Transparent, compact, always-on — the layer your viewers actually see.

Dashboard /dashboard

Your private control room (localhost only): full stats, the activity calendar, theming and settings.

Live page /live

A public, shareable page of what you're building right now — deploy it so anyone can follow along.

Your keys never touch the stream

VibeLog is built around one hard invariant: only names you typed and numeric stats ever reach the public state. No file paths, no diffs, no raw prompts, no secrets. OAuth tokens live in a local secrets.json at chmod 600, and a remote-request gate keeps tunneled viewers on read-only public routes. Stream with confidence.
